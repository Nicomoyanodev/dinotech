# DINOTECH – Catálogo web

Publica **https://dinotech.ar** en GitHub Pages.

Este repo tiene solo la tarea automática (`.github/workflows/actualizar.yml`): cada 4 horas baja el código del repo
[zona-gamer](https://github.com/Nicomoyanodev/zona-gamer), arma la web de DINOTECH y la publica.
Para cambiar datos, logo o stock, ver la sección "Sucursal DINOTECH" del README de zona-gamer.
